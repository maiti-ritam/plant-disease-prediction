Plant Disease Prediction using CNN and Streamlit

This project uses a Convolutional Neural Network (CNN) to classify 38 different plant diseases (and healthy leaves) from leaf images. It consists of two main components:

Jupyter Notebook (Plant_Disease_Prediction_CNN_Image_Classifier.ipynb): A complete workflow for downloading the dataset, preprocessing the images, and building, training, and evaluating the CNN model using TensorFlow and Keras.

Streamlit Web App (app.py): A user-friendly web interface that loads the pre-trained model and allows users to upload their own plant leaf images for real-time disease prediction.

📋 Features

Model Training: A complete, reproducible notebook to train the plant disease classifier from scratch.

Web Interface: An interactive and easy-to-use web app built with Streamlit.

Real-Time Prediction: Upload an image (JPG, JPEG, or PNG) and get an instant classification.

38 Classes: The model is trained on the PlantVillage dataset and can identify 38 distinct plant/disease combinations.

High Performance: The simple CNN model achieves ~86% validation accuracy.

🛠️ Technology Stack

Model & Training: TensorFlow (Keras)

Web App: Streamlit

Data Processing: NumPy, Pillow (PIL)

Data Download: Kaggle API

Plotting: Matplotlib

📂 Project Components

Plant_Disease_Prediction_CNN_Image_Classifier.ipynb

This notebook contains all the code for the model's creation.

Key steps:

Sets random seeds for reproducibility.

Downloads the "PlantVillage" dataset using the Kaggle API.

Creates ImageDataGenerator pipelines for training and validation (80/20 split).

Defines a sequential CNN model.

Trains the model for 5 epochs.

Evaluates the model and plots accuracy/loss curves.

Crucially, it saves the final model as plant_disease_prediction_model.keras and the class labels as class_indices.json.

app.py

This is the Streamlit web application.

It loads the plant_disease_prediction_model.keras and class_indices.json files.

It provides a file uploader for the user.

It preprocesses the uploaded image to match the model's input requirements (224x224, rescaled).

It runs the prediction and displays the formatted result.

Required Files (Generated by the notebook)

plant_disease_prediction_model.keras: The trained Keras model.

class_indices.json: The dictionary mapping class indices to their names.

🚀 How to Run This Project

Follow these steps to get both the training notebook and the web app running.

Part 1: Train the Model (Using the Notebook)

This part is necessary to generate the .keras and .json files required by the web app.

Clone the Repository (or download the files)

# (If this were a git repo)
# git clone [https://your-repo-url.git](https://your-repo-url.git)
# cd plant-disease-prediction


Install Dependencies
You will need the following Python libraries:

pip install tensorflow numpy pillow matplotlib jupyterlab kaggle streamlit


Set up Kaggle API

To run the data download cell in the notebook, you need your Kaggle API credentials.

Go to your Kaggle account, click your profile icon, and select "Account".

Click "Create New API Token" to download kaggle.json.

Place this kaggle.json file in the expected location (e.g., C:\Users\<Your-Username>\.kaggle\ on Windows or ~/.kaggle/ on Linux/Mac) OR update the notebook path to point to its location.

Run the Jupyter Notebook

Launch Jupyter Lab:

jupyter lab


Open Plant_Disease_Prediction_CNN_Image_Classifier.ipynb.

Run all the cells from top to bottom.

This will download the data, train the model, and—most importantly—save the plant_disease_prediction_model.keras and class_indices.json files in your project directory.

Part 2: Run the Streamlit Web App

Once you have the .keras and .json files from Part 1, you can run the web app.

Check Your Directory
Make sure the following files are all in the same folder:

app.py (the Streamlit app)

plant_disease_prediction_model.keras (from the notebook)

class_indices.json (from the notebook)

Run the App

Open your terminal in that directory.

Run the following command:

streamlit run app.py


View in Browser

Streamlit will automatically open your web browser to the application's local URL (usually http://localhost:8501).

You can now upload a plant leaf image and click "Classify" to see the prediction.
